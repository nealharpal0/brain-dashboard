Deze pagina staat openbaar op GitHub Pages, je notities niet. Ze worden rechtstreeks uit je privé-repo in deze browser geladen, met een token die alleen op dit apparaat blijft.

  1. Maak een fine-grained token aan.
  2. Bij Repository access: kies Only select repositories en dan second-brain.
  3. Bij Permissions: zet Contents op Read-only. Meer is niet nodig.
  4. Plak de token hieronder.
